# 🚗 CarDekho Vehicles Performance Overview Dashboard

## 📊 Project Overview
● This project presents an interactive **Vehicles Performance Overview Dashboard** built using the **CarDekho dataset**.  
● The dashboard analyzes **car pricing, mileage, vehicle age, and seller distribution** to provide both **budget car insights** and **luxury car comparisons**.  
● It helps users understand market trends and vehicle performance across multiple dimensions.

---

## 🎯 Objectives
● Analyze car pricing trends across different brands  
● Understand mileage categories, vehicle age distribution, and seller types  
● Enable brand-level filtering for deeper insights  

---

## 📈 Key Insights & Features

### 🔹 Pricing Analysis
● **Below 10 Cars:** Highlights affordable models like *Maruti Wagon R, Celerio, S-Presso, and Hyundai i10*  
● **Top 10 Expensive Cars:** Showcases premium vehicles such as *Ferrari GTC4Lusso, Rolls-Royce Ghost, Bentley Continental, and BMW series*  

### 🔹 Mileage Analysis
● Categorizes vehicles into **above 20 km/l** and **below 20 km/l** mileage segments  
● Helps identify **fuel-efficient brands** and **performance-oriented vehicles**  

### 🔹 Vehicle Age Distribution
● Vehicles are classified into:  
  ● Below 5 years  
  ● Exactly 5 years  
  ● Above 5 years  
● Useful for analyzing **resale value trends** and **vehicle usage patterns**  

### 🔹 Seller Type Distribution
● Vehicles listed by:  
  ● Dealers  
  ● Individual sellers  
  ● Trustmark dealers  
● **Dealers dominate** the overall vehicle listings  

### 🔹 Interactive Filtering
● Brand-based slicers enable **dynamic filtering** across all dashboard visuals  

---

● Pivot Tables & Charts – Data analysis and insights

## 📌 Use Cases
● Market trend analysis for buyers and sellers
